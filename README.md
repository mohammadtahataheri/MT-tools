# MT Tools 🛠️

**MT Tools** is a lightweight Windows utility suite designed to provide essential everyday tools in one simple and user-friendly application.  
The project focuses on practicality, clean design, and accessibility for users who want useful tools without unnecessary complexity.

---

## ✨ Features

MT Tools includes a collection of commonly used utilities, such as:

- Calculator  
- Translator  
- Search File
- Paint
- Lightweight GUI built with Python  

> The toolset may expand over time as new features are added.

---

## 🖥️ Platform Support

- **Operating System:** Windows 10 / 11  
- **Architecture:** x64  
- Designed specifically for Windows desktop environments
